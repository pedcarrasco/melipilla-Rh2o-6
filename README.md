El uso excesivo de fertilizantes genera altos costos y problemas ambientales, como la contaminación del agua y la emisión de gases de efecto invernadero. Para optimizar este proceso, proponemos una solución IoT basada en sensores de nutrientes y pH del suelo, que miden los niveles de nitrógeno, fósforo y potasio. Estos datos permiten un sistema automatizado de riego y fertilización que ajusta la cantidad de fertilizante según las necesidades del cultivo. Utilizando Arduino o Raspberry Pi para el control y análisis de datos con Python, se predice el momento ideal para fertilizar, mejorando la eficiencia, reduciendo el impacto ambiental y minimizando costos operativos.
